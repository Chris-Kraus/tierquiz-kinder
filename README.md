# Tierquiz für Kinder

Kleine Website mit einem Tierquiz für Kinder.

## Lokal starten

Voraussetzung: [Node.js](https://nodejs.org/) (inkl. npm) installiert.

```bash
npm install
npm run dev
```

Der Dev-Server (Vite) startet danach unter der in der Konsole angezeigten Adresse
(standardmäßig `http://localhost:5173`) mit Hot-Reload.

Weitere Skripte:

```bash
npm run build   # Produktions-Build nach dist/
npm run preview # Produktions-Build lokal ansehen
npm run lint    # ESLint-Prüfung
npm run format  # Code mit Prettier formatieren
```

Technischer Hintergrund (Tech-Stack, Projektstruktur): siehe
[`docs/workflow/architecture.md`](docs/workflow/architecture.md).
